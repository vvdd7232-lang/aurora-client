# Aurora Client — Fabric 1.21.11

Современный легковесный клиент для Minecraft с плавным непиксельным интерфейсом.
Откройте меню клавишей **Right Shift**. Клик по карточке модуля включает/отключает его.

## Возможности
- 🎨 Сглаженный интерфейс со скруглёнными углами, плавными анимациями и мягкими тенями
- 🎨 Кастомный логотип Aurora (северное сияние)
- ⚙️ Работающие переключатели модулей с анимацией
- **Встроенные рабочие модули:**
  - **Fullbright** — максимальная яркость мира в любое время суток
  - **Zoom** — оптическое приближение (FOV 30°)
  - **NoHurtCam** — отключает тряску экрана при получении урона
  - **AutoSprint** — постоянный спринт при движении

## Сборка
Требуется Java 21. В корне проекта выполните:
```bash
./gradlew build
```
(На Windows: `gradlew.bat build`)

Готовый `.jar` появится в `build/libs/`. Переместите его в папку `mods` вместе с Fabric API.

## Структура проекта
```
ru.aurora.client/
├── AuroraClient.java       # Точка входа, регистрация клавиши и событий
├── gui/AuroraScreen.java   # Главное меню клиента (новый smooth UI)
├── modules/                # Система модулей
│   ├── Module.java         # Базовый класс модуля
│   ├── ModuleManager.java  # Реестр всех модулей
│   └── impl/               # Реализации модулей
├── mixin/                  # Mixin'ы для Minecraft
└── util/DrawUtil.java      # Утилиты рендера (скруглённые углы)
```
