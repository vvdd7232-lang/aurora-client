# Aurora Client — Fabric 1.21.11

Пока это только клиентский визуальный макет, без игровых функций. Откройте меню клавишей **Right Shift**. Категории слева можно переключать; карточки справа декоративные и ничего не включают.

## Сборка
Требуется Java 21. В корне проекта выполните `./gradlew build` (Windows: `gradlew.bat build`). Готовый jar появится в `build/libs/`.
